## CLI Commands

### ▶️ `eval-patient` group to analyze individual patients

| **Description** | Group to chain together loading a patient's data with downstream tasks (e.g. scoring, visualization)                                                                                                                                                                                                                                                                                                                                                                 |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `eval-patient [OPTIONS] PATIENT_ID COMMAND1 [ARGS]... [COMMAND2 [ARGS]...]...`                                                                                                                                                                                                                                                                                                                                                                                       |
| **Help**        | `eval-patient --help`: Show help message and exit.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Arguments**   | `PATIENT_ID`: Patient ID (e.g. `0055`).                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Options**     | `-d, --search-dir DIRECTORY`: Directory(ies) to search for input files. <br>`-g, --graph-pattern TEXT`: Glob pattern to search for vascular graph JSON files within `search-dir` (e.g. '\*{id}\*.json'). <br>`-l, --legacy-networkx-format`: Use legacy attribute names to parse NetworkX-internal graph data (i.e. 'links' instead of 'edges'). <br>`-i, --ctpa-pattern`: Glob pattern to search for CPTA image files within `search-dir`. (e.g. '\*{id}\*.nii.gz') |
| **Commands**    | `mastora`: Compute Mastora score on the graph. <br>`qanadli`: Compute Qanadli score on the graph.<br>`visualize`: Visualize attribute values in the graph an interactive PyVis-generated HTML.                                                                                                                                                                                                                                                                       |
| **Examples**    | `eval-patient -d data/PERSEVERE/graphs -g '*{id}*.json' -l -i '*{id}*.nii.gz' 0055`                                                                                                                                                                                                                                                                                                                                                                                  |

### ▶️ `eval-population` command to analyse clinical attributes and measures across multiple patients

| **Description** | Group to chain together loading data for a whole population with downstream tasks (e.g. scoring, plotting)                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `eval-population [OPTIONS] COMMAND1 [ARGS]... [COMMAND2 [ARGS]...]...`                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Help**        | `eval-population --help`: Show help message and exit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Options**     | `-c, --clinical-data FILE`: Path to a CSV file of clinical data to pair with patients' graphs. <br>`-d, --search-dir DIRECTORY`: Directory(ies) to search for input files. <br>`-g, --graph-pattern TEXT`: Glob pattern to search for files within `search-dir` (e.g. '\*{id}\*.json'). <br>`-l, --legacy-networkx-format`: Use legacy attribute names to parse NetworkX-internal graph data (i.e. 'links' instead of 'edges'). <br>`-i, --ctpa-pattern`: Glob pattern to search for CPTA image files within `search-dir`. (e.g. '\*{id}\*.nii.gz') |
| **Examples**    | Load graphs and clinical data of patients listed in a CSV: `eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -g '*{id}*.json' -l`                                                                                                                                                                                                                                                                                                                                                                                       |

#### ▶ `plot` subcommand to plot distributions of clinical attributes and/or scores across the population

| **Description** | Plot distribution of attribute(s) with respect to other attribute(s).                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `eval-population plot [OPTIONS]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Help**        | `eval-population plot --help`: Show help message and exit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Scores**      | For how to precompute scores before plotting them, see the sections below on the [`qanadli` command](#-qanadli) or [`mastora` command](#-mastora).                                                                                                                                                                                                                                                                                                                                                                                       |
| **Options**     | `-c, --col TEXT`: Attribute(s) to plot along the columns of the figure. <br>`-r, --row TEXT`: Attribute(s) to plot along the rows of the figure. <br>`--categorical-plot {violin\|histogram}`: Type of plot to use for categorical attributes.                                                                                                                                                                                                                                                                                           |
| **Examples**    | Plot distribution of Qanadli and Mastora (global) score with respect to risk stratification: <br>`eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -g '*{id}*.json' -l qanadli mastora global plot -r qanadli -r mastora_global -c risk --categorical-plot violin` <br>Plot distribution of Mastora (central) score with respect to age and BNP: <br>`eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -g '*{id}*.json' -l mastora central plot -r mastora_global -c age -c bnp` |

### Chainable subcommands

#### ▶ `rv-lv-ratio`

Measure the volumetric ratio between the heart's right and left ventricles, segmented from CTPA images.

> [!IMPORTANT]
> If you do not have pre-computed segmentation masks of the ventricles, before you run this command the first time,
> be sure to install [TotalSegmentator](https://github.com/wasserth/TotalSegmentator) and to configure a [license for it](https://backend.totalsegmentator.com/license-academic/).

| **Description** | Command to compute the right-over-left ventricle volume ratio on the CTPA image(s)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `GROUP_COMMAND rv-lv-ratio [OPTIONS]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Input**       | For how to specify input, see the sections above on the [`eval-graph` command](#-eval-graph) or [`eval-population` command](#-eval-population).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Help**        | `GROUP_COMMAND rv-lv-ratio --help`: Show help message and exit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Options**     | `-d, --annotations-ventricles-dir DIRECTORY`: Directory containing the right and left ventricles masks to compute ratio from. If empty, masks will be inferred using TotalSegmentator and stored here for future use. <br>`-m, --mask-pattern TEXT`: Glob pattern to search for segmentation masks within `annotations-ventricles-dir` (e.g. '\*{id}\*.nii.gz'). <br>`-lv, --lv-label INT`: Label value for the left ventricle in the masks. Default to the label used by TotalSegmentator with the `heartchambers_highres` task. <br>`-rv, --rv-label INT`: Label value for the right ventricle in the masks. Default to the label used by TotalSegmentator with the `heartchambers_highres` task. |
| **Examples**    | Compute RV/LV ratio for one patient: `eval-patient -d data/PERSEVERE/graphs -d data/PERSEVERE/ctpa_images -i '*{id}*.nii.gz' -l 0055 rv-lv-ratio -d data/PERSEVERE/annotations_ventricles -m '*{id}*.nii.gz'` <br>Compute RV/LV ratio for a whole population: `eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -d data/PERSEVERE/ctpa_images -i '*{id}*.nii.gz' -l rv-lv-ratio -d data/PERSEVERE/annotations_ventricles -m '*{id}*.nii.gz'`                                                                                                                                                                                                                            |

#### ▶ `qanadli`

Details of how the Qanadli score is computed are provided [here](scores/formulas.md#qanadli-score).

| **Description** | Command to compute the Qanadli obstruction score on the graph(s)                                                                                                                                                                                                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `GROUP_COMMAND qanadli [OPTIONS]`                                                                                                                                                                                                                                                                                                  |
| **Input**       | For how to specify input, see the sections above on the [`eval-graph` command](#-eval-graph) or [`eval-population` command](#-eval-population).                                                                                                                                                                                    |
| **Help**        | `GROUP_COMMAND qanadli --help`: Show help message and exit.                                                                                                                                                                                                                                                                        |
| **Options**     | `-oa, --obstruction-attr TEXT`: Edge attribute to use as obstruction values. <br>`-po, --partial-obstruction-thresh FLOAT`: Transversal obstruction threshold to consider a segment partially obstructed. <br>`-to, --total-obstruction-thresh FLOAT`: Transversal obstruction threshold to consider a segment totally obstructed. |
| **Examples**    | Compute Qanadli score for one patient: `eval-graph -d data/PERSEVERE/graphs -g '*{id}*.json' -l 0055 qanadli` <br>Compute Qanadli score for a whole population: `eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -g '*{id}*.json' -l qanadli`                                                         |

#### ▶️ `mastora`

Details of how the Qanadli score is computed are provided [here](scores/formulas.md#mastora-score).

| **Description** | Command to compute the Mastora obstruction score on the graph(s)                                                                                                                                                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `GROUP_COMMAND mastora [OPTIONS]`                                                                                                                                                                                                                                                                                    |
| **Input**       | For how to specify input, see the sections above on the [`eval-graph` command](#-eval-graph) or [`eval-population` command](#-eval-population).                                                                                                                                                                      |
| **Help**        | `GROUP_COMMAND mastora --help`: Show help message and exit.                                                                                                                                                                                                                                                          |
| **Arguments**   | `{central\|peripheral\|global}`: Variant of the score to compute, that only considers obstructions in central (i.e. mediastinal and lobar), peripheral (i.e. segmental), or both (i.e. global) arteries towards in the final score.                                                                                  |
| **Options**     | `-oa, --obstruction-attr TEXT`: Edge attribute to use as obstruction values. <br>                                                                                                                                                                                                                                    |
| **Examples**    | Compute Mastora (central) score for one patient: `eval-graph -d data/PERSEVERE/graphs -g '*{id}*.json' -l 0055 mastora central` <br>Compute Mastora (peripheral) score for a whole population: `eval-population -c data/PERSEVERE/clinical_data.csv -d data/PERSEVERE/graphs -g '*{id}*.json' -l mastora peripheral` |

#### ▶️ `visualize`

| **Description** | Command to visualize attribute values in the graph(s) using an interactive PyVis-generated HTML                                                                                                                                                                                                                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Usage**       | `GROUP_COMMAND visualize [OPTIONS]`                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Input**       | For how to specify input, see the sections above on the [`eval-graph` command](#-eval-graph) or [`eval-population` command](#-eval-population).                                                                                                                                                                                                                                                                                             |
| **Help**        | `GROUP_COMMAND visualize --help`: Show help message and exit.                                                                                                                                                                                                                                                                                                                                                                               |
| **Options**     | `-c, --color-attr TEXT`: Edge attribute to color edges in the graph visualization. Ignored in favor of obstruction attribute used by score if `--debug-score` is also specified. <br> `-d, --debug-score [qanadli\|mastora_central\|mastora_peripheral\|mastora_global]`: Score for which to display intermediate values in the visualization, to help debugging. <br>`-o, --output-dir`: Directory to save the generated HTML files under. |
| **Examples**    | Visualize the graph of a pateint: `eval-graph -d data/PERSEVERE/graphs -g '*{id}*.json' -l 0055 visualize` <br>Visualize intermediate results of Qanadli score for one patient: `eval-graph -d data/PERSEVERE/graphs -g '*{id}*.json' -l 0055 qanadli visualize -d qanadli -o ~/pyvis_graphs`                                                                                                                                               |
